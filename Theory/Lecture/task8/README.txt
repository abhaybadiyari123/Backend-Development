1. Open Chrome and press F12 to open DevTools.
2. Go to the Network tab.
3. Visit http://localhost:3000/students (Express) or
   http://localhost:5000/students (Flask).
4. Click on the request in the Network tab.
5. Observe the request method, status code, response headers, and response body.
6. Save the screenshot as screenshots/request-response-cycle.png.
